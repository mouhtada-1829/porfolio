# Portfolio — one-page éditorial

## Scope and mode

Surface : accueil one-page, React 19 + Vite + CSS pur, build code-led. Mode Experience : le travail mène dès le premier viewport, l'interface s'efface. Visiteur : recruteurs et responsables techniques qui évaluent un stage, une alternance ou un premier poste junior en génie logiciel, au Sénégal ou à l'international, souvent depuis le CV, LinkedIn ou GitHub. Job : comprendre le positionnement, voir Senguichet en démo, vérifier les certifications, télécharger le CV, contacter. Preuve : Senguichet (web + mobile + paiements locaux), deux vidéos, COREX, huit certifications, double cursus logiciel/cyber. Contraintes : français, one-page, 390→1440, WCAG AA, reduced motion, vidéos lazy, pas de violet, pas de fausses captures, témoignages ou métriques inventées.

## Chosen direction and memorable moment

La salle des relais (candidate 6 de ma liste ordonnée) : baie de brassage, étiquettes gravées, circuits traçables, lampes d'état. Moment mémorable : survoler un projet trace son chemin de signal (mobile → API → backend → paiement → validation) avec un témoin qui avance.

## Direction contract

THESIS: Le portfolio est une baie de brassage : chaque projet est un circuit traçable de bout en bout, chaque certification une ligne validée. Il refuse le hero générique « carte + dégradé » et les barres de compétences.

OWN-WORLD: Acier laqué ivoire-gris #E8E4DB, encre charbon #1B1D1A, ambre signal #C8751A, vert validé #2F6B4F ; étiquettes gravées, rails de baie, câblage lacé, cartes de schéma, lignes 1px, grotesque mécanique et mono pour les adresses ; pas de violet, pas de néon.

STORY: Le recruteur comprend en dix secondes : génie logiciel d'abord, cybersécurité en profondeur. Il voit le circuit Senguichet, lance la démo, vérifie les certifications, télécharge le CV et écrit.

FIRST VIEWPORT: Baie pleine largeur : plaque de nom en haut à gauche (nom + « Génie logiciel / Cybersécurité »), bandeau d'état à droite (stage/alternance), circuit Senguichet tracé au centre (mobile → API → backend → paiement → validation) avec un témoin qui avance ; boutons gravés « Voir la démo » (primaire) et « Télécharger le CV » sous le circuit ; rail vertical de sections à gauche.
